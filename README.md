# Adaptive Threat Shield — Браузерне розширення

Система адаптивного оцінювання та реагування на вебзагрози з урахуванням контексту користувацьких дій (Дипломна робота).

## 🚀 Як запустити та протестувати MVP:

### 1. Збірка розширення:
```bash
npm run build
```
Зібране розширення знаходиться в директорії `.output/chrome-mv3`.

### 2. Запуск у режимі розробки (HMR):
```bash
npm run dev
```

### 3. Встановлення в Google Chrome / Chromium-браузер:
1. Відкрийте сторінку керування розширеннями: `chrome://extensions`.
2. Увімкніть **«Режим розробника» (Developer mode)** у правому верхньому кутку.
3. Натисніть кнопку **«Завантажити розпаковане розширення» (Load unpacked)**.
4. Оберіть папку:
   `.output/chrome-mv3`

### 4. Тестування сценаріїв загрози:
Відкрийте тестовий HTML-стенд у браузері (наприклад, тестову сторінку авторизації або оплати).

На стенді представлено 4 сценарії:
1. **Легітимна форма авторизації** — успішний сабміт без перешкод.
2. **Form Action Mismatch** — спроба відправки пароля на сторонній сервер блокується, кнопка деактивується, виводиться попередження.
3. **Autofill Phishing** — виявлення прихованих інпутів для крадіжки картки та CVV через автозаповнення.
4. **Валідація банківської картки (Luhn algorithm)** — виявлення вводу картки та накладання керованого тертя безпеки.
