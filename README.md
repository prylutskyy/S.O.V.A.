## Проблема: Інтернет стає занадто небезпечним
Ви коли-небудь відчували тривогу, вводячи свої конфіденційні дані на новому сайті? Шахраї стають все розумнішими. Фішинг, підроблені форми, приховані поля для викрадення даних, маніпулятивні чати на фріланс-біржах - традиційні антивіруси не бачать цих загроз, адже це соціальна інженерія, а не віруси. Ви залишаєтесь сам на сам із шахраями.

## Рішення: С.О.В.А.
С.О.В.А. - це не просто блокувальник реклами чи сканер шкідливих посилань. Це інтелектуальне браузерне розширення нового покоління, яке працює як ваш особистий експерт із кібербезпеки в режимі реального часу. Воно аналізує контекст сторінки, перевіряє поведінку скриптів, моніторить приховані форми та застосовує штучний інтелект для розпізнавання хитрих шахрайських схем у чатах та на сайтах.

[Місце для скріншоту: Модальне вікно попередження про небезпеку на сторінці з підсвіченою загрозою (наприклад, виявлено приховану форму або підозрілий редирект).]

## Чому варто спробувати С.О.В.А. саме зараз?

- **Проактивний захист від соціальної інженерії та диверсій**: Аналізує підозрілі патерни у спілкуванні, розпізнає спроби виманювання даних та **виявляє спроби ворожого вербування чи диверсій** (фотофіксація ТЦК, відстеження адрес і номерів авто посадовців, прикриття рухом опору за ст. 114-2 ККУ, підпали військових авто чи релейних шаф залізниці за крипту, шахрайство з OLX-доставкою), попереджаючи вас ДО того, як ви зробите фатальну помилку.
- **Двомовний векторний аналіз намірів (Tier 1.5 Subword N-Grams)**: Повноцінна підтримка української та російської мов. Алгоритм нечутливий до одруків, сленгу чи навмисної обфускації слів, працює локально в браузері всього за 0.5 мс без жодного витоку трафіку.
- **Ізоляція сесій у SPA-додатках (Telegram Web, OLX)**: Розумний трекінг клієнтського роутингу. При переході між різними чатами система миттєво очищує локальний стан і ковзне вікно, усуваючи ризик переносу тривоги на безпечних співрозмовників.
- **Евристичний ШІ-аналіз**: Використовує динамічні детектори, які адаптуються до різних контекстів без затримок і зайвого навантаження на систему. Підтримує високошвидкісні хмарні (Groq LPU) та локальні моделі для максимальної приватності.
- **Захищене персональне сховище (Vault)**: Ваші найцінніші дані (наприклад, дівоче прізвище матері, секретні коди, номери документів) зберігаються лише в оперативній пам'яті (in-memory) під надійним криптографічним захистом (PBKDF2, AES-GCM, Salted HMAC). С.О.В.А. автоматично блокує спроби сайту витягнути цю інформацію через невидимі поля за O(1).
- **Блискавична швидкість**: Написано з фокусом на продуктивність. Розширення не уповільнює ваш браузер, працюючи непомітно на фоні.
- **Абсолютний контроль**: Детальна статистика, можливість налаштувати винятки, HUD-дебагер (Ctrl + Shift + D) та повна прозорість дій системи.

[Місце для скріншоту: Вкладка "Сховище" (Vault) з розблокованим інтерфейсом, де видно захищені типи даних та їх статус.]

## Як це працює?
1. **Фільтрація форм**: С.О.В.А. сканує кожну форму на сайті. Якщо виявлено приховані поля, які намагаються непомітно зібрати ваші дані - форма блокується або знешкоджується.
2. **Моніторинг чатів та векторний спектр**: Розширення виявляє спроби перенаправлення на зовнішні ресурси, нав'язування шахрайських схем або кримінальних завдань за винагороду.
3. **Підвищена пильність**: При найменшій підозрі система переходить у режим "Підвищеної пильності", посилюючи контроль за всіма вашими діями на сайті. Ви завжди можете скинути цей стан одним кліком, якщо впевнені у безпеці сторінки.

[Місце для скріншоту: Вкладка налаштувань, де видно опції вибору ШІ-моделі (Groq/Local), керування довіреними сайтами та налаштування локального детектора мови.]

## Для розробників та ентузіастів

Цей проєкт має відкритий вихідний код, і ми запрошуємо вас долучитися до його розвитку.

### Як скомпілювати проєкт самостійно

Для роботи з проєктом вам знадобиться встановлений Node.js (v18+) та npm.

1. **Клонуйте репозиторій:**
   ```bash
   git clone <url-вашого-репозиторію>
   cd sova
   ```

2. **Встановіть залежності:**
   ```bash
   npm install
   ```

3. **Запуск автоматизованих тестів (Vitest, 53 сьюти / 483 тести):**
   ```bash
   npm test
   ```

4. **Запуск у режимі розробки (з автоматичним перезавантаженням):**
   ```bash
   npm run dev
   ```
   Це згенерує папку розширення, яку ви зможете завантажити у браузер (через `chrome://extensions/` -> "Завантажити розпаковане розширення").

5. **Збірка для продакшену:**
   ```bash
   npm run build
   ```
   Готовий, оптимізований бандл Manifest V3 знаходитиметься у папці `.output/chrome-mv3`.
