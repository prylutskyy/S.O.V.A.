# Перевірка пакета рецензування

Оновлення після отримання рецензій: виконано [повний локальний baseline](LOCAL_EVALUATION_REPORT.md) на 600 кейсах за замороженими попередніми ШІ-еталонами. Фінальний офлайн-прогін — 932/932, TypeScript і build успішні. Нижче збережені перевірки інструмента на момент його створення; твердження про відсутність прогнозів стосується саме того попереднього етапу.

Дата: 2026-10-10. Корпус: `sova-blind-review-v1`.

SHA-256: `3f75c7a6e924bb4367beac3b6c33549d8dcc156a62bb7991af6fcca0ce011705`.

`npx vitest run tests/review`: **16/16**, 2 файли. Це технічні перевірки засобу рецензування, **не показник точності розпізнавання загроз**.

## Що перевірено

- По 300 кейсів A/B, 600 унікальних ID, непорожні репліки та підтримані ролі.
- Хеш згенерованих сліпих текстів відповідає manifest; 30 пакетів покривають корпус без повторів.
- Вибірка має 25 A + 25 B і збігається з вибіркою сторінки.
- У JSON для рецензентів та вбудованому наборі HTML немає авторських міток, сюжетних назв і зв’язків з оригіналом.
- Приватна карта містить 60 оригіналів і їхні парні перетворення.
- Чернетки без вибраної оцінки не стають завершеним ambiguous/safe автоматично.
- Зміни тексту одразу записуються; повторне завантаження документа в DOM-середовищі відновлює їх.
- Перехід між кейсами зберігає оцінку; загроза потребує типу та репліки-доказу.
- Недоступне сховище показує помилку, не повідомляє про успішне збереження.
- Експорт розділяє завершені відповіді й чернетки, не включає тексти діалогів.
- Імпорт відновлює відповіді; помилковий хеш, невідомі/повторені ID, неіснуючі докази та некоректні дії відхиляються до зміни даних.

## Межі перевірки

HTML перевірено в Happy DOM. Спроба відкрити локальний файл через браузерний інструмент відхилена його політикою URL; обхід не застосовувався. Візуальний вигляд, реальне завантаження файла експорту та поведінку localStorage для file:// потрібно підтвердити у браузері користувача. Сторінка показує стан збереження й дозволяє експортувати резервну копію.

Тексти створено ШІ, який знав проєкт. Авторська розмітка не є незалежним еталоном. Після перетворень можливі зміни читабельності чи змісту, тому B теж потребує рецензування. Подібні вступи й парні кейси не можна рахувати як незалежні спостереження. Людська вибірка не гарантує правильність усього корпусу.

Прогнози локального детектора не отримувалися; live API не викликався; новий корпус не додано до метрик dashboard або навчання. Наявні production-алгоритми не змінені.
